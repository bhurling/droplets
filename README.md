# Droplets

Bootstrap scripts for DigitalOcean droplets, with setup and recovery instructions
kept alongside each configuration.

## Available setups

| Setup | Purpose |
| --- | --- |
| [T3 Code server](./t3-server/README.md) | An Ubuntu host running T3 Code, Codex, and GitHub CLI, reachable from your other devices through T3 Connect |

Start with the setup's README for requirements, installation, and sign-in steps.
